# AutoLog Pro account deletion page

A small bilingual (Russian and English) static site that explains how to request deletion of an AutoLog Pro account and associated cloud data.

## Publish with GitHub Pages

The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the `site` directory on every push to `main` and can also be started manually.

In the repository settings, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. Then check the **Actions** tab for the deployment. The site URL for this repository is:

https://fen417.github.io/AutoLogProDeletingAccount/

## Local preview

Open `site/index.html` in a browser. The site has no build step or external dependencies.
